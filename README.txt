NutriTrack PWA
==============

האפליקציה שומרת את כל הנתונים מקומית בדפדפן באמצעות localStorage.
אין שרת, אין חשבון ואין שליחת נתונים החוצה.

התקנה באייפון כ-PWA:
1. יש להעלות את התיקייה הזו לכתובת HTTPS (דרישת Safari עבור Service Worker/PWA).
2. לפתוח את הכתובת ב-Safari באייפון.
3. ללחוץ Share / שיתוף.
4. לבחור "Add to Home Screen" / "הוסף למסך הבית".
5. לפתוח מהאייקון במסך הבית.

לאחר הפתיחה הראשונה האפליקציה נשמרת לעבודה אופליין.

חשוב: iOS אינו מאפשר להתקין PWA מלאה ישירות מקובץ ZIP או file:// בלבד. נדרש HTTPS פעם אחת לצורך ההתקנה וה-Service Worker.
